# 《中国式管理》知识库

> 作者：曾仕强（1934–2018）| 成书/课程：2000 年代（时代光华管理课程，全 12 集）
> 作者背景：英国莱斯特大学管理哲学博士、美国杜鲁门大学行政管理硕士；台湾交通大学教授；专研「人际关系与沟通」「中国人的民族性与管理」
> 双尾彗星定位：**中国人的思维模式、组织管理**（本 skill 内作为"在中国式组织里怎么做事"的操作手册）

## 核心思想概览

一句话：**管理是"修己安人"的历程——先把人做好，才谈得上管人。**

曾仕强的整个体系建立在与美日管理的对照上：

| | 美国式 | 日本式 | **中国式** |
|---|---|---|---|
| 哲学基础 | 个人主义 | 集体主义 | **交互主义**（二合一） |
| 核心口号 | 我要—我成 | 同生—共荣 | **修己—安人** |
| 侧重 | 专业性、专业知识 | 一致性、团体精神 | **变动性，一切看情况** |
| 对错 | 清晰化、公开化 | — | **模糊化**（层级越高越没有对错） |

**三大主轴**（全书的骨架）：
1. **以人为主**——事在人为，所有事都是人做出来的
2. **因道结合**——理念共识比制度化管理更有效；道不同不相为谋
3. **依理应变**——变的依据是"合理"，不是"合法"

围绕这三大主轴，六个管理面向各自展开：计划（随时调整）、执行（无形控制）、考核（明暗兼顾）、沟通（不明言）、领导（情理法）、激励（衡情论理）。

**读这本书的正确姿势**：它不是"中国人都这样，所以你只能这样"的宿命论，而是"**这个环境里的实际运作规则是这样，你要做事就得先看懂它**"。看懂不等于认同，但看不懂就一定吃亏。

## 核心概念框架

### 1. 修己安人：管理的目的是"安"
- 管理是**修己安人**的历程：先修自己，再安别人
- "安"是最终目的：**不安的利润不能要**
- 安人不是讨好，是让组织成员各守其分、和合为一
- 安的路径：**开心 → 交心 → 共同关心 → 同心**

### 2. 交互主义：把二看成三
西方思维是二选一（个人主义 vs 集体主义），中国式是**二合一**：
- 不是"在集体中牺牲个人"，也不是"个人优先"，而是**"在集体中完成个人"**
- 典型表达：**凡事未定案之前十分民主，一旦拍板定案相当独裁**
- 推论：很多看似矛盾的做法（既讲情又讲法、既民主又集中）不是虚伪，是**把两端合起来想**

### 3. 树状组织精神
- 根部吸水，源源不断供应树干；树干毫不保留地让枝叶予取予求
- 对应中国人的心理需求：**"你办事，我放心"**
- 反面：**上侵下职**——上司抢下属的活干，妨害员工学习成长，破坏上下关系

### 4. 持经达变：经是方，权是变
- **经**（原则）是方的，规规矩矩；**权**（变通）是变的，要变得合理
- 持经达权 = 有原则，但**因人、因事、因时、因地而应变**
- 判断标准：**只要合理，怎样变动都可以**
- 关键区分：**圆通 = 随机应变；圆滑 = 投机取巧**——差别在动机纯不纯

### 5. 外圆内方
- **方**是方针、准则（不变的原则）；**圆**是随机应变（变得合理）
- 可以圆通，不可以圆滑；可以和稀泥式和谐，不可以和稀泥
- 原则和变通**必须有切点**，否则就是乱变

### 6. ★ 不明言：沟通以不明言为基础
- **讲话讲太清楚，自己就站在亮处；站在亮处，所有人都攻击你**
- 不明言才有回旋余地
- 操作顺序：**先含含糊糊，摸清楚以后才清清楚楚**——反过来先讲清楚就是压宝，压错就完了
- 这不是含糊其辞，是**保留调整空间**

### 7. ★ 妥当性 > 真实性
- 西方人求真，中国人求美（"妥当"）
- **不说实在话，不等于骗人**——说的是"妥当话"
- 核心判据：**讲话第一个要让对方听得进去**；听不进去，讲得再对再真诚都等于白讲

### 8. ★ 讲"第三种话"
经典场景：老板问"你吃饱了没有？"

| 回答 | 后果 |
|---|---|
| "吃饱了" | 老板以为你不用管了 → 留守的就是你 |
| "还没吃" | 太实，老板难做 |
| **"下午比较忙"** | 老板知道该给你买便当，你也留了余地 ✅ |

另一场景：老板问"你有没有空？"
→ **不回答有没有空，直接答"我马上来"**。有没有空是我的事，你要的是我过来。

**要点**：第三种话不是含糊，是**让对方没办法得寸进尺**。

### 9. ★ 对上 / 对同辈 / 对下：三套申诉方式
| 对象 | 方式 | 原因 |
|---|---|---|
| **对上** | **不说话就是申诉** | 上级说你错，你吭气就倒霉；他不吭声，上级反而会说"你没有错，你为什么不讲" ——这时你要说"**有啦，多少有点错**" |
| **对同辈** | 不要直接说人错 | 你说我错，我承认我有错——**你难道没有错吗**？最后两人都没面子 |
| **对下** | 更不能直接说 | 职位比你低的人被你当众指出错，只会找机会报复 |

**对上让上级向你道歉，等于在自己家里等死。**

### 10. ★ 会而不议、议而不决、决而不行
流行说法骂这三句是中国人办事的毛病。曾仕强的判断相反：**这是最了不起的地方**。

| 三句 | 正解 |
|---|---|
| **会而不议** | 会前充分沟通，把反对意见提前化解掉，会上就不用议 |
| **议而不决** | 会上有分歧时，主席**不裁决**——主席是协调人，不是裁决人，裁决就得自己扛 |
| **决而不行** | 决议不等于执行到底，后面有变化还得"看着办"——**留调整空间才是负责** |

开会前必做：**先想哪几个人会反对，先去找他把问题化解掉**。

### 11. ★ 情理法：三层各用一套
- **嘴巴永远讲情，心里有理，法放在肚子里当腹案**
- **凡是把规定挂在嘴边的人，人际关系都很差**（"法就伤感情"）
- 层级分工：**高层以情为主、中层以理为主、基层以法为主**
- 目的不是讲情，是**通过情把人引到理**（由情入理）
- 核心判据：**中国人最讲道理，但千万不要去跟中国人讲道理**——他只相信自己的道理。**给他面子，他自己就讲理；不给他面子，他就蛮不讲理**

### 12. 面子与脸：两回事
- **脸 = 生命（人格、原则）**，**面子 = 感情（一时的）**
- 可以要面子，**不能不要脸**；可以没有面子，不能没有脸
- 骂人最重的话是"不要脸"——意思是**不讲理**，与面子无关

### 13. 核心班子：靠差别待遇，不靠一视同仁
- 嘴上一定讲一视同仁，**心里一定要差别待遇**
- 为什么？因为组织靠的是**核心班子**：有事替你想、替你分忧，你才照顾得过来
- 核心班子怎么来：**外围 → 考核 → 拉近 → 核心**，层层考验
- 风险：心腹是君子则旺，是小人则亡

### 14. 经得起考验：听话不对，不听话也不对
经典场景：老板把年轻人叫来，让他擦自己办公室的窗。

| 反应 | 结果 |
|---|---|
| 生气："凭什么叫我擦窗" | 经不起考验 ❌ |
| 老老实实一直擦到底 | 也经不起考验 ❌（老板想"我会叫科长的来擦玻璃吗"） |
| **擦两下就走** | ✅ 明白"办公室有陌生人，不方便让你听" |

**判据**：凡是没神经病的人讲出神经病的话，一定有道理。

### 15. 对"讨好"高度警觉
- 一个人不断送你东西，先问**他要什么**
- 西方人"吃人家的嘴不会软"（礼是礼，事是事，分开看）；中国人**合起来看**，吃了嘴就软
- 所以：**不习惯别人讨好，一讨好就警觉**——这是防御机制，不是多疑

### 16. 听什么也不要相信，也不要不相信
- 听了就信 → 上当；听了就不信 → 孤立
- 正确做法：**多听，不当场表态，等要用的时候再综合判断**
- 表现：平时很随和，紧要关头很有原则

## 与双尾彗星思维框架的映射

| 曾仕强的判断 | 彗星的对应条目 |
|---|---|
| **情理法三层：嘴巴讲情、心里讲理、法当腹案** | **二-21「赏罚的度只有一把手能把握」**：规则要严，但必须留说情和宽恕的空间——完全是同一套（只减刑不加刑） |
| **中国人只相信自己的道理，给他面子他才讲理** | **八-03「讲道理的人」**：讲道理的只能和讲道理的人抱团；对不讲理的人，你没法让他讲理。曾仕强给的是"为什么"：因为面子先于道理 |
| **核心班子 = 层层考验 + 差别待遇** | **二-26「职场两件事：学流程，占信息位」**：信息位就是核心班子的入口 |
| **经得起考验：擦两下就走** | **二-22「体制内拼的是谁更能经得起别人恶心」**：都是"考验不是任务本身，是你读不读得懂" |
| **树状组织：你办事我放心** | **二-04「下位者的处事哲学」**：中策就是找一个能合理分配资源、赏罚分明的领导跟着他 |
| **不明言、留回旋余地** | **四-43「凡我辩不过的都是对的」**：都要求"别把话说死"，都靠保留调整空间来降低风险 |
| **对讨好高度警觉** | **三-12「谈价钱就谈买卖」**：先判断对方在谈什么关系，再决定怎么回应 |
| **会前沟通化解，不在会上裁决** | **七-19「目标越多越做不好」**：正面冲突的成本远高于提前化解 |
| **修己安人：先把人做好再谈管理** | **十一-09「合理」**：修己＝格物致知＋知行合一；安人＝让对方也"安"（能持续） |

**最根本的共振**：曾仕强和彗星都在说同一件事——**先看懂规则的实际运作方式，再谈怎么在里面做事**。区别是曾仕强讲"中国人为什么不按西方规则来"，彗星讲"任何规则下你都得找对打法"。

**一个直接冲突点**：彗星在 **八-06「平庸者用数量的暴力围殴做事的人」** 里主张"要么把事做成，要么把人处好，别卡中间"；曾仕强的主张是"**做人做事兼顾并重，透过好好做人来把事情做好**"。这不是矛盾——彗星讲的是**取舍（资源有限时必须选）**，曾仕强讲的是**顺序（在中国式组织里，做人本身就是做事的前置条件）**。两者可以合起来：先做人在前，但当真冲突时要有取舍的决断。

## 双尾彗星视角的关键追问

1. **"这套东西是描述还是提倡？"**——曾仕强常被批评为"把陋习讲成智慧"。彗星式的问法是：**这是事实判断（中国人确实这样）还是价值判断（中国人应该这样）**？读的时候必须分清。
2. **"这套方法对谁有利？"**——不明言、讲妥当话，对**上位者**最有利（保留弹性、不担责任），对下位者则是信息劣势。要问：我在什么位置，该用哪一套。
3. **"年轻人还吃这一套吗？"**——这是本书最大的时代风险。90/00 后对"面子""含蓄""揣摩上意"的耐受度明显下降。**规则在变，书是 2000 年代的**。
4. **"酒桌文化还算不算？"**——**不算**。用户已明确：这部分过时了。见下节。
5. **"和西方管理能不能混用？"**——曾仕强的答案是"日本人拿中国的管理哲学去运用西方的管理科学"。也就是说：**哲学层用中国的，工具层可以用西方的**。这个分层是他最实用的一个提法。

## 关键案例

1. **老板问"吃饱了没有"**：三种答法三种命运。**第三种话不是含糊，是让对方无法得寸进尺。**

2. **老板叫科长擦窗**：真擦、发火都输，**擦两下就走**才是读懂信号。**考验的内容从来不是任务本身。**

3. **上级说你错了**：争辩 → 上级道歉 → 你在家等死；**不吭气 → 上级反而让你讲 → 你说"有啦，多少有点错"** → 一年升三级。

4. **会议两派意见**：主席当场裁决 → 输的一方全力阻挠；**宣布"再商量" → 私下找支持的一方 → 让他自己去沟通** → 事情办成且没人失面子。

5. **给高级领导让座**：直接让年轻人挪位 → 他不服；**说"领导来了让他坐你旁边"** → 他自己走开。**给面子，对方就配合。**
